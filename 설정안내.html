Google Sheets 연동 설정 안내

이 안내를 따라 설정하면, 응답자가 설문을 제출할 때마다 자동으로 Google Sheets에 데이터가 저장됩니다.

응답자가 설문 작성
→
"설문 제출" 클릭
→
Google Sheets에 자동 저장
→
엑셀 분석파일에 붙여넣기

설정 절차 (약 5분 소요)

Step 1: Google Sheets 생성

  4. 첫 번째 행(A1~AP1)에 아래 헤더를 입력합니다 (복사 붙여넣기):

Step 2: Google Apps Script 생성

  1. Google Sheets 상단 메뉴에서 확장 프로그램 > Apps Script를 클릭합니다.
  2. 기존 코드를 모두 지우고, 아래 코드를 붙여넣습니다:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('AHP응답');
    if (!sheet) {
      sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    }

    var data = JSON.parse(e.postData.contents);
    var row = data.values;

    sheet.appendRow(row);

    return ContentService.createTextOutput(
      JSON.stringify({ result: 'success' })
    ).setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    return ContentService.createTextOutput(
      JSON.stringify({ result: 'error', message: error.toString() })
    ).setMimeType(ContentService.MimeType.JSON);
  }
}

Step 3: 웹 앱으로 배포

  1. Apps Script 상단의 "배포" > "새 배포"를 클릭합니다.
  2. 왼쪽의 톱니바퀴 아이콘 옆 "유형 선택"에서 "웹 앱"을 선택합니다.
  3. 설정을 다음과 같이 합니다:
    • 설명: AHP 설문 수집
    • 다음 사용자 인증정보로 실행: 나 (본인 계정)
    • 액세스 권한이 있는 사용자: 모든 사용자
  4. "배포" 버튼을 클릭합니다.
  5. 처음 실행 시 권한 승인이 필요합니다 → "권한 검토" → 본인 계정 선택 → "허용"
  6. 배포가 완료되면 "웹 앱 URL"이 표시됩니다. 이 URL을 복사합니다.

Step 4: 설문지에 URL 붙여넣기

  1. AHP_설문조사.html 파일을 메모장(또는 VS Code)으로 엽니다.
  2. Ctrl+H (찾기/바꾸기)를 사용합니다.
  3. 찾을 내용: YOUR_GOOGLE_APPS_SCRIPT_URL_HERE
  4. 바꿀 내용: Step 3에서 복사한 웹 앱 URL을 붙여넣기
  5. 저장합니다.
설정 완료! 이제 설문지를 응답자에게 보내면, 제출할 때마다 Google Sheets에 자동 저장됩니다.

데이터를 엑셀 분석파일로 옮기는 방법

Step 5: Google Sheets에서 데이터 복사

  1. Google Sheets에서 응답 데이터가 쌓인 것을 확인합니다.
  2. 데이터 영역(헤더 제외)을 선택합니다.
  3. Ctrl+C로 복사합니다.

Step 6: 엑셀 분석파일에 붙여넣기

  1. 충남_AHP_분석_결과_v2.xlsx를 엽니다.
  2. "응답데이터" 시트로 이동합니다.
  3. B5 셀을 클릭합니다 (응답자1의 응답일시 열).
  4. Ctrl+V로 붙여넣기합니다.
  5. 자동으로 기하평균, 가중치, CR, 차트 등이 모두 계산됩니다.
주의: Google Sheets의 열 순서와 엑셀 분석파일의 열 순서가 일치하도록 설계되어 있습니다. Google Sheets의 헤더나 열 순서를 변경하지 마세요.

자주 묻는 질문

Q: 설문지를 어떻게 배포하나요?

AHP_설문조사.html 파일을 다음 방법으로 배포할 수 있습니다:

  • 방법 1 (권장): GitHub Pages, Netlify, Vercel 등 무료 호스팅에 업로드 후 URL 공유
  • 방법 2: HTML 파일을 이메일에 첨부하여 전송 (응답자가 브라우저에서 열기)
  • 방법 3: 구글 드라이브에 업로드 후 공유 링크 배포

Q: 응답이 제대로 들어오는지 어떻게 확인하나요?

Google Sheets를 열어두면 실시간으로 새로운 행이 추가되는 것을 확인할 수 있습니다.

Q: 설문을 수정하고 싶으면 어떻게 하나요?

Apps Script를 수정한 경우, 반드시 "배포" > "배포 관리" > "새 버전"으로 다시 배포해야 반영됩니다.
